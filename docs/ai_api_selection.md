### 품질 비교 방법 (각 후보별 10분)

각 서비스의 웹 테스트 화면(Playground 등)에서 아래 두 프롬프트를 그대로 넣고 결과를 비교한다.

**① 문의 답변 (F-03): 근거 밖 질문을 지어내지 않는지 확인**

```
[시스템] 당신은 소상공인 매장의 고객 문의 답변을 돕는 도우미입니다. 반드시 아래 매장 정보·메뉴·FAQ만
근거로 답하세요. 근거에 없는 내용은 '매장에 직접 문의해 주세요'라고 답하세요.

[매장] 온기 카페, 영업시간 09:00~21:00, 휴무일 월, 연락처 02-000-0000
[메뉴]
- 아메리카노: 4,500원
- 카페라떼: 5,000원
[FAQ]
- Q: 주차 되나요? / A: 건물 뒤편에 2대 주차 가능합니다.
[고객 문의]
화요일 저녁 8시에 가도 되나요? 그리고 콜드브루 있나요? 가격도 알려주세요.
```

좋은 답: 화요일 20시는 영업 중이라고 답하고, 콜드브루는 메뉴에 없으니 매장에 문의하라고 안내한다. 가격을 지어내면 탈락.

**② 홍보 문구 (F-04): 형식 규칙을 지키는지 확인**

```
인스타그램 게시글을 작성하세요. 첫 문장에서 시선을 끌고 끝에 해시태그를 붙이세요.
- 홍보 대상: 카페라떼 (5,000원)
- 키워드: 가을, 따뜻함
- 길이: 50~300자
- 해시태그: 3~10개
- 어조: 친근하고 감각적인 말투, 이모지 1~3개
```

좋은 답: 300자 이내, 해시태그 3~10개, 가격 5,000원 정확.

## 5. 키 발급 후 할 일

1. 공식 사이트에서 키를 발급받는다. 사용 한도(월 예산 상한) 설정 메뉴가 있으면 **반드시 낮게 설정**한다.
2. 프로젝트 폴더의 `.env`에만 넣는다.
   ```
   AI_PROVIDER=claude          # 또는 gemini, openai
   AI_API_KEY=발급받은_키
   AI_MODEL=공식_문서의_모델_이름
   ```
3. **절대 하지 말 것**: 코드에 키 직접 쓰기, Git 커밋, 카카오톡·디스코드에 키 붙여넣기, 스크린샷에 키 노출.
4. 키가 유출됐다고 의심되면 즉시 해당 사이트에서 키를 삭제하고 새로 발급한다.
5. 팀원은 실제 키 없이 `AI_PROVIDER=mock`으로 개발한다. 실제 API 결과가 필요하면 정회성에게 요청하거나 시연용 PC에서 확인한다.
6. 사용 내역은 `docs/ai_usage_log.md`에 기록한다.

## 6. Gemini 키 발급과 연결 확인

담당: 정회성. 화면 구성은 바뀔 수 있으니 메뉴 이름이 조금 달라도 비슷한 항목을 찾습니다.

1. [Google AI Studio](https://aistudio.google.com)에 **개인 Google 계정**으로 로그인합니다. 학교 계정은 관리자 정책으로 막혀 있을 수 있습니다.
2. 약관에 동의합니다.
3. **Get API key → Create API key**를 누릅니다. Google Cloud 프로젝트를 고르라고 하면 새로 만듭니다. `AIza`로 시작하는 키를 복사합니다.
4. **결제(Billing)는 연결하지 않습니다.** 연결하지 않으면 무료 등급으로만 동작해서 요금이 나갈 일이 없습니다.
5. AI Studio 모델 목록에서 무료로 쓸 수 있는 **Flash 계열 모델 이름**을 확인해 복사합니다.
6. 내 PC의 `.env`에만 넣습니다.
   ```
   AI_PROVIDER=gemini
   AI_API_KEY=복사한_키
   AI_MODEL=복사한_모델_이름
   ```
7. 연결을 확인합니다.
   ```
   python -m app.adapters.ai.check
   ```
   - `성공: ...` → 위 결정 기록의 "연결 확인"과 "사용할 모델"을 채웁니다.
   - `HTTP 400` → 키가 틀렸거나 복사가 덜 됨 (Gemini는 잘못된 키를 400으로 알려 줌)
   - `HTTP 403` → 키 권한 문제. 키를 새로 만들어 봄
   - `HTTP 404` → 모델 이름 오타. AI Studio 목록에서 다시 복사
   - `호출 한도 초과 (HTTP 429)` → 무료 한도 초과. 자동으로 2번 다시 시도한 뒤에도 나면 1분쯤 기다렸다 재실행
8. 평소 개발할 때는 `AI_PROVIDER=mock`으로 돌려 둡니다. 실제 API는 13주차 검증 실험과 발표 시연 때만 씁니다.

Claude나 OpenAI로 다시 바꾸려면 `AI_PROVIDER`, `AI_API_KEY`, `AI_MODEL` 세 줄만 바꾸면 됩니다.
